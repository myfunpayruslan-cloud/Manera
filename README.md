# AURA COFFEE

Интерактивный сайт кофейни: React, TypeScript, Vite, React Three Fiber, Drei, Three.js, GSAP, Framer Motion и Tailwind CSS.

## Запуск

Требуется Node.js 22.12+ (проверено на 24).

```sh
npm ci
npm run dev -- --port 5173
```

Проверка production-сборки: `npm run build`. Просмотр: `npm run preview`.

Чашка, блюдце, ручка, зёрна и пар созданы программно. Рисунок пенки генерируется через CanvasTexture. В меню доступно вращение мышью/пальцем. На мобильных снижается разрешение и отключаются летающие зёрна; сцены вне экрана не перерисовываются. Поддерживается prefers-reduced-motion.

Корзина сохраняется в localStorage. Размер влияет на цену, количество и удаление пересчитывают сумму. Форма — демонстрационная: данные не передаются, оплата не выполняется. Адрес, контакты и карта демонстрационные. Фотографии загружаются с images.unsplash.com; для их проверки в облачной среде требуется разрешить этот домен в сетевых настройках.
