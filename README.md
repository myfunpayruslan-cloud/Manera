# AURA COFFEE

Интерактивный сайт кофейни: React, TypeScript, Vite, React Three Fiber, Drei, Three.js, GSAP, Framer Motion и Tailwind CSS.

## Запуск

Требуется Node.js 22.12+ (проверено на 24).

```sh
npm ci
npm run dev -- --port 5173
```

Проверка production-сборки: `npm run build`. Просмотр: `npm run preview`.

Чашка, блюдце, ручка, зёрна и пар созданы программно. Рисунок пенки генерируется через CanvasTexture. В меню доступно вращение мышью/пальцем. На мобильных снижается разрешение и отключаются летающие зёрна; сцены вне экрана не перерисовываются. Поддерживается prefers-reduced-motion.

Корзина сохраняется в localStorage. Размер влияет на цену, количество и удаление пересчитывают сумму. Форма — демонстрационная: данные не передаются, оплата не выполняется. Адрес, контакты и карта демонстрационные. Фотографии загружаются с images.unsplash.com; для их проверки в облачной среде требуется разрешить этот домен в сетевых настройках.

## 3D art direction

`src/CoffeeScene.tsx` содержит шесть собственных процедурных моделей: керамический капучино, высокий стеклянный латте, маленький эспрессо, широкий flat white, стакан холодного кофе со льдом и керамическую матча. Геометрия чашек имеет наружную и внутреннюю поверхность, скруглённый край и отдельную изогнутую ручку. Блюдце построено по плавному профилю. Внешние GLB и лицензируемые текстуры не используются.

Освещение — студийные отражающие панели, физические материалы, ACES и контактные тени. Пенке задана выпуклая поверхность и детерминированная текстура розетты; пар — прозрачные анимированные шейдерные ленты. В стеклянных напитках используется непрерывный объём со смешением молочного и кофейного слоёв. Форма зёрен включает углубление по центральному шву.

На телефоне снижены DPR, детализация и разрешение окружения/теней. Вне экрана цикл рендеринга остановлен. При prefers-reduced-motion отключены постоянные движения; ручное вращение меню остаётся доступным. Камера героя реагирует на прокрутку, меню поддерживает OrbitControls.

Проверка обновления: `npm run build`, переключение всех шести напитков в Chromium, заказ Matcha Latte 350 мл (430 ₽, две порции — 860 ₽), уменьшение количества, демо-оформление, проверка ширины 390 px. Фотореализм и производительность на конкретном мобильном GPU требуют проверки на самом устройстве.
